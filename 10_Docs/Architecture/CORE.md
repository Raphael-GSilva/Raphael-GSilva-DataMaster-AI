# Core

## Objetivo

O Core é o coração do Raphael-GSilva DataMaster AI.

Nenhum agente poderá executar tarefas diretamente.

Todas as solicitações passarão pelo Core.

## Responsabilidades

- Inicializar o sistema
- Carregar configurações
- Carregar memória
- Gerenciar agentes
- Escolher modelos
- Controlar ferramentas
- Registrar logs
- Gerenciar sessões

## Regras

O Core nunca executa IA.

O Core apenas coordena.
